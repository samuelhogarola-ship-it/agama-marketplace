# Modelo unico de anuncio

Este es el patron base para todos los anuncios de TodoPlastico. Sirve para mantener consistencia, velocidad de revision y calidad de catalogo.

## Campos obligatorios

- Empresa verificada o activa.
- Titulo concreto del producto.
- Categoria del catalogo.
- Descripcion tecnica y comercial.
- Precio MXN.
- Como se vende: `unidad`, `kg` o `g`.
- Compra minima: entero positivo, sin decimales.
- Ubicacion: al menos ciudad o area.
- Forma de contacto: email, telefono o WhatsApp.
- Dato de contacto.
- Fotos claras del producto.

## Enlaces

El enlace externo es opcional. Si se usa, debe pertenecer a la web propia del anunciante o a una pagina del mismo dominio. No se aceptan acortadores, marketplaces externos, landings de terceros ni redirecciones pensadas para ocultar el destino real.

## Prohibiciones

- Pigmentos, masterbatch, aditivos y colorantes.
- Spam, productos no permitidos o contenido ajeno a la industria plastica.
- Telefonos, emails o WhatsApp dentro del titulo, descripcion o fotos.
- Imagenes genericas, confusas o sin relacion directa con el producto.

## Disponibilidad

TodoPlastico no usa la accion "marcar como vendido". El catalogo esta pensado para fabricantes y proveedores, no para venta de piezas unicas. Cuando un producto no este disponible temporalmente, el anunciante debe pausarlo; cuando vuelva a estar disponible, debe reactivarlo o reenviarlo a revision si se ha modificado.
