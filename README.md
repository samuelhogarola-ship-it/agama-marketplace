# AGAMA Marketplace

Portal de compraventa de **productos de plástico** en Ciudad de México, operado por AGAMA.

**Objetivo estratégico:** que el mayor número posible de proveedores de productos plásticos de CDMX pase por AGAMA — visibilidad de marca + datos de valor sobre el mercado (oferta, demanda, precios, búsquedas).

## Reglas de negocio (v1)

| Regla | Detalle |
|---|---|
| Perfiles | Solo perfiles **profesionales** (empresa/proveedor). Sin perfiles particulares por ahora. |
| Plan gratuito | Hasta **5 productos** publicados. |
| Plan Pro | Suscripción de pago para publicar más de 5 (fase posterior, no MVP). |
| Fotos | Hasta **5 fotos** por producto. |
| Envíos | Fuera de plataforma: se acuerdan entre comprador y vendedor. Sin pasarela de pago de productos en v1. |
| Mensajería | Chat interno comprador ↔ vendedor, obligatorio para contacto. |
| Moderación IA | Toda publicación y mensaje pasa por un watcher de IA. Solo se permite contenido sobre **productos de plástico**. |

## Contenido prohibido (moderación)

- Cualquier cosa que no sea un producto de plástico o servicio directamente relacionado.
- **Pigmentos, masterbatch y aditivos** — prohibidos aunque sean del sector, para no dar escaparate a la competencia directa de AGAMA.
- Ilegal, ofensivo, spam, datos de contacto en fichas para saltarse la mensajería (v1: se marca para revisión).
