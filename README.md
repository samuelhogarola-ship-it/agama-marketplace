# TodoPlástico

Plataforma B2B gratuita de descubrimiento para la **industria del plástico en México**, impulsada por AGAMA.

**Objetivo estratégico:** reunir empresas, productos, servicios, anuncios y contenido editorial del sector plástico para generar tráfico cualificado, visibilidad de AGAMA y datos de valor sobre oferta y demanda.

## Reglas de negocio (v1)

| Regla | Detalle |
|---|---|
| Perfiles | Solo perfiles **profesionales** (empresa/proveedor). Sin perfiles particulares por ahora. |
| Plan gratuito | Hasta **5 anuncios** publicados. |
| Monetización | Sin pagos, comisiones ni planes de pago en Fase 1. |
| Fotos | Hasta **5 fotos** por anuncio. |
| Contacto | Fuera de plataforma: web, teléfono, email, WhatsApp o enlace externo visible. |
| Mensajería | No hay mensajería interna en Fase 1. |
| Moderación IA | Toda publicación pasa por moderación. Solo se permite contenido del sector plástico. |

## Contenido prohibido (moderación)

- Cualquier cosa que no sea producto, servicio o anuncio B2B directamente relacionado con la industria plástica.
- **Pigmentos, masterbatch y aditivos** — prohibidos aunque sean del sector, para no dar escaparate a la competencia directa de AGAMA.
- Ilegal, ofensivo, spam o datos de contacto incrustados en título, descripción o imágenes. El contacto va en campos específicos.
